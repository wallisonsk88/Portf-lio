# Portfolio - Wallison Rangel

Modular and modern portfolio built with React, Vite, Tailwind CSS, and Framer Motion.

## 🚀 Technologies

- **Frontend**: React.js
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 🛠️ Installation

1. Clone the repository
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Build for production: `npm run build`
